# kml-ride-navi

Google マイマップで作ったツーリングルートを、そのまま iPhone のナビとして使うための Web アプリです。
ルート探索はせず、**自分で引いたルートの上を案内すること**に特化しています。

**アプリ：** https://mecaorrrrr.github.io/kml-ride-navi/

インストール不要で、Safari で開くだけで使えます。ホーム画面に追加しておくと、アプリのように全画面で開けます。

## できること

- **マイマップの共有リンクからルートを読み込む**：リンクを貼って「読み込む」を押すだけで、KML ファイルのダウンロードは不要です。KML・KMZ・GPX ファイルからも読み込めます
- **日ごとのルートを選ぶ**：マイマップでレイヤを日ごとに分けておけば、走る日を選べます。逆向きにも走れます
- **曲がり角の案内（矢印と音声）**
  - 「次の信号を右」「2つ目の信号を左」のように、信号の数で案内します
  - 交差点名、入る道の国道番号（「国道20号です」）も案内します
  - 高速の入口・出口・JCT を IC 名や方面つきで案内します。出口とJCTは 2km・500m・直前の3回案内します
  - 側道への分岐や、道なりのカーブ・料金所の車線の分かれ目のような、案内しなくてよい分岐は案内しません
- **SA・PA**：進行方向側（左側）の SA/PA を、地図と画面に距離つきで表示し、2km 手前と直前に音声で知らせます
- **経由地**：マイマップに置いた地点のうち、ルートの近くにあるものを経由地として、表示と音声で知らせます
- **到着予想**
  - 道路の種類（高速・国道・県道・細い道）、カーブの多さ、信号の数から所要時間を見積もります
  - 走りながら、直近の実績で少しずつ補正します。表示が細かく前後しないよう、到着時刻はゆっくり動かしています
  - ナビ開始前にも、メニューに休憩なしの所要時間の目安を出します
- **ルートを外れたとき**：画面の色と矢印で、ルートがある方向を示します
- **縦画面・横画面の両方に対応**：横画面では左に案内、右に地図を表示します
- **グローブでも押せる＋／－ボタン**：ピンチ操作なしで地図を拡大・縮小できます。ナビ中は、速度に応じた自動の縮尺からの増減として覚えます
- **夜間表示、画面の消灯防止、走行シミュレーション**

## 使い方

1. マイマップでルートを作り、共有設定を「リンクを知っている全員」が閲覧できるようにする
2. アプリのメニューで、共有リンクを貼り付けて「読み込む」を押す
3. ルートが複数あれば、走る日を選ぶ
4. 道路データの取得が終わるのを待つ（下記）
5. 「ナビ開始」を押す。iPhone は画面ロック中に位置情報が止まるので、画面を点けたままマウントしてください

マイマップでルートを直したら、もう一度「読み込む」を押すと最新になります。

## 道路データについて

曲がり角・信号・IC・国道番号・SA/PA の判定には、[OpenStreetMap](https://www.openstreetmap.org/) の道路データを使います。

- ルートを選ぶと、ルート沿いの道路データを公開の [Overpass API](https://overpass-api.de/) から自動で取得し、端末に保存します。一度取れば圏外でも使えます
- 取得はルート約 50km ごとに 1 回の問い合わせで、公開サーバーの混み具合によって数分〜十数分かかります。**出発前に Wi-Fi のある場所で済ませておく**のがおすすめです
- 一部の区間が取れなかった場合は、メニューの「取れなかった区間を取り直す」で残りだけ取得できます
- 道路データが取れない区間は、ルートの線の形から曲がり角を見つけて案内します

## 制約

- ルートの探索や、ルートを外れたときの再探索はしません。外れたときはルートの方向を示すだけです
- 案内の正しさは、OpenStreetMap のデータの正しさに左右されます。交差点名が登録されていない場所も多くあります
- 到着予想は休憩時間を含みません
- Overpass API は世界中で共有されている無料のサーバーなので、混雑時は取得に時間がかかります

## 構成

ビルド不要の HTML ファイル 1 つ（`ride-navi.html`）でできています。`index.html` はそこへ転送するだけのページです。

- 地図：[Leaflet](https://leafletjs.com/) と OpenStreetMap のタイル
- KMZ の展開：[JSZip](https://stuk.github.io/jszip/)
- 音声案内：ブラウザの音声合成（Web Speech API）
- 道路データの保存：IndexedDB
